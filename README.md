# Finanzübersicht

Eine kleine browserbasierte Anwendung, um Finanzen im Blick zu behalten:

- Laufende Einnahmen erfassen
- Ausgaben als **fix** oder **variabel** unterscheiden
- Rücklagen als **Zugang** oder **Abgang** verwalten
- Künftige Ausgaben planen
- Alle Daten lokal im Browser speichern (LocalStorage)

## Starten

Einfach `index.html` im Browser öffnen.
