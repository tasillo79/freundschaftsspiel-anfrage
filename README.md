# Team Aufgaben-Notizen Tool

Ein leichtgewichtiges Tool für Teams, um Aufgaben als Notizen zu erfassen:

- Titel der Aufgabe
- Detailbeschreibung
- Frist
- Zuständigkeit (optional)
- Erledigt/Offen Status

## Starten

```bash
npm start
```

Danach im Browser öffnen:

- `http://localhost:3000`

## Tests

```bash
npm test
```
